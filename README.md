# RunSub Website

Dependency-free RunSub marketing website designed for reliable Vercel deployment.

## Deploy settings

- Framework Preset: Other
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist
- Environment Variables: none

## Local preview

```bash
npm run start
```

## Structure

- `index.html` main page
- `src/styles.css` design system and layout
- `src/main.js` small animation script
- `public/favicon.svg` icon
- `build.mjs` copies files to `dist/`
